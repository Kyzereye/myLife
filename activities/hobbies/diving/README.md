# Diving

My dive log, all in one place. Right now my dives are recorded in several places. This folder is where they all come together.

## Files

| File | What it's for |
|---|---|
| [dives.csv](dives.csv) | The log. One row per dive, numbered in order. |
| `certs.md` | Certifications, card numbers, and dates. *To add.* |
| `gear.md` | My gear and service dates. *To add.* |

## Logging a dive

Open Claude in myLife and say what you dove. Claude adds the row to `dives.csv`. Leave a field blank if you don't know it.

Columns: dive number, date, site, location, trip (the file name in `activities/travel/`, if any), max depth (ft), bottom time (min), water temp (°F), visibility (ft), buddy, notes.
